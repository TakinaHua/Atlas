# Preserved earlier versions

- `early-prototype/`: formatted earliest static prototype.
- `vanilla-frontend/`: formatted JavaScript frontend replaced by TypeScript/Next.js.
- `express-backend/`: former temporary server, retained for reference.
- `original-project/`: original manifests, README, and former syntax checker.
- `atlas-frontend-mvp.zip`: unchanged supplied ZIP.

These are reference copies, not the active application. Their older README instructions and relative serving paths describe their original checkout. Use the Git checkpoints in `docs/versions.md` to run a complete previous version. Regression tests for the preserved frontend still run through the root `npm test` command.
